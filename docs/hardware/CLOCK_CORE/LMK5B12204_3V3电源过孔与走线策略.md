# LMK5B12204 — 3.3V 电源过孔位置与走线层策略（rev2）

本文回答三个问题：3.3V 进磁珠之前是不是先经过电容？3.3V 电源过孔打在哪里？3.3V 走哪一层？

> rev2 更正：rev1 漏掉了磁珠输入侧的电容，并沿用了旧板的位号。本版位号全部取自当前 `CLOCK_CORE.kicad_pcb` 的焊盘网络。

---

## 1. 结论

| 问题 | 答案 |
|------|------|
| 是否先经过电容再到磁珠 | **是。** 每一路都是 π 型：`+3.3V → 输入电容 → 磁珠 → 10 µF → VDDxx → 引脚 100 nF` |
| 过孔打在哪里 | **打在输入电容的 +3.3V 焊盘外侧**，电流先经过输入电容焊盘，再进磁珠 pad1 |
| 3.3V 走哪一层 | 推荐 **L3 (In2.Cu) 整面 +3.3V**；当前 In2.Cu 是空的，+3.3V 铺在 F.Cu 上 |
| 磁珠之后怎么走 | 域内电源不再打回 L3，在元件所在面用短线连 10 µF 和引脚电容 |

## 3. 为什么输入电容要排在磁珠前面、过孔要先到电容

π 型滤波 C–FB–C 里，输入电容有两个作用：

1. **挡住来自 3.3V 母线的高频噪声**：噪声在进磁珠之前就被旁路到地。
2. **挡住本域漏回母线的噪声**：VDDO 输出级的开关电流会穿过磁珠反向漏回 +3.3V，输入电容把它就地吸收，不让它通过公共母线串到 VDDXO、VDDPLL 这些敏感域。

输入电容和磁珠 pad1 在电气上是同一个节点，但在 PCB 上每毫米走线约 1 nH。100 MHz 时 1 nH 的感抗是 0.63 Ω，已经和 100 nF 电容的阻抗在同一量级。所以**电流路径上的先后顺序是有意义的**：

```
推荐：   过孔 ─→ [C_in +3.3V 焊盘] ─→ [FB pad1] ─磁珠─ [FB pad2] ─→ 10µF ─→ 引脚
                     │
                  GND过孔

不推荐： 过孔 ─→ [FB pad1] ─磁珠─ ...
                   │
              (一段支线) ─→ [C_in]        ← 电容挂在支线末端，高频旁路打折
```

**具体尺寸：**

| 项 | 要求 |
|----|------|
| 电源过孔位置 | C_in 的 +3.3V 焊盘外侧（背向磁珠一侧），间距 ≤ 0.3 mm |
| C_in 与 FB pad1 | 焊盘紧挨，间隙 ≤ 0.5 mm，可直接用铜皮连成一块 |
| C_in 的 GND | 焊盘外 0.4 mm 内打 GND 过孔，落 L2 |
| 过孔规格 | 0.6/0.3 mm，嘉立创常规工艺；不用盘中孔 |

若空间实在不够，过孔可以打在 C_in 焊盘和 FB pad1 之间的连接铜上，仍然是可接受的；要避免的只是"过孔直接落在磁珠 pad1，电容挂在另一头"。

## 4. 3.3V 走哪一层

### 4.1 当前状态

| 层 | 当前铜 |
|----|-------|
| F.Cu | 信号 + +3.3V / +5V / OCXO_VCC 等多块铺铜 |
| In1.Cu | GND 整面 |
| In2.Cu | **空，没有任何铜** |
| B.Cu | 部分磁珠和去耦电容 |

### 4.2 推荐：+3.3V 整面放到 In2.Cu

- **F.Cu 空间让给信号**：8 对差分输出、XO_P、PRIREF 都在 F.Cu，+3.3V 铺铜会把它们挤得绕行。
- **B.Cu 的磁珠也能就近取电**：FB2、FB3、FB4 在背面。+3.3V 在 In2.Cu 时，背面输入电容旁打一个过孔即可；现在 +3.3V 在 F.Cu，背面元件要从正面过孔穿过来。
- **In2.Cu 可以分割**：F.Cu 的信号参考的是 In1.Cu 的 GND，In2.Cu 上把 +3.3V、+5V、OCXO_VCC 分块不影响信号回流。

### 4.3 磁珠之后不要回 In2.Cu

磁珠 pad2 之后的 VDDxx 是本域专用网络。在元件所在的那一面用 ≥ 0.3 mm 的短线连到 10 µF 和引脚电容；引脚电容在另一面时，用一个过孔穿过去，这个过孔穿 In2.Cu 时要开 antipad，不能碰 +3.3V。

## 5. 完整路径（以 VDDPLL1 为例，元件在 B.Cu）

```
LDO 输出 ─(F.Cu)─ 过孔 ─ In2.Cu +3.3V 整面 ─ 过孔(C38 外侧) ─→ C38 焊盘 ─→ FB3 pad1
   ─磁珠─ FB3 pad2 ─(B.Cu 短线)─ C39 10µF ─ C53 100nF ─ 过孔 ─→ U5 pin27 VDD_PLL1

回流：U5 E-PAD ─ 过孔阵列 ─ In1.Cu GND 整面 ─ 各电容 GND 过孔
```

## 6. 检查清单

| 项 | 判据 |
|----|------|
| 七路电源 | 过孔 → 输入电容 → 磁珠 → 输出电容 → 引脚电容，顺序不颠倒 |
| 电源过孔 | 在输入电容 +3.3V 焊盘外侧 ≤ 0.3 mm |
| 输入电容与磁珠 | 焊盘间隙 ≤ 0.5 mm |
| 每颗电容 GND | 焊盘外 0.4 mm 内有 GND 过孔 |
| +3.3V | 在 In2.Cu 整面铺铜，U5 散热过孔阵列区域避开 |
| VDDxx 过孔穿 In2.Cu | 开 antipad，不连 +3.3V |
| In1.Cu | GND 整面，不分割 |
| VDDDIG | 确认是否需要补磁珠后的 10 µF |
